| Estado                        | Significado práctico                                                                                                      | ¿Implica un problema?                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **[DONE] / [HECHO]**          | La prueba o tarea fue ejecutada y completada.                                                                             | **No.** Solo indica ejecución.                                          |
| **[OK]**                      | El elemento evaluado cumple con la condición esperada por la prueba de Lynis.                                             | Generalmente **no**.                                                    |
| **[ENCONTRADO]**              | Lynis detectó el elemento, archivo, servicio, módulo o configuración que estaba buscando.                                 | **Depende del contexto.** Encontrado no significa seguro ni inseguro.   |
| **[NO ENCONTRADO]**           | Lynis no detectó el elemento que estaba buscando.                                                                         | **Depende del contexto.** Puede ser positivo o negativo.                |
| **[NINGUNO]**                 | No se encontraron elementos que cumplieran la condición evaluada.                                                         | **Depende de la prueba.**                                               |
| **[HABILITADO]**              | La función o mecanismo evaluado está habilitado.                                                                          | Depende de si debería estar habilitado.                                 |
| **[DESHABILITADO]**           | La función o configuración está deshabilitada.                                                                            | Depende del control evaluado.                                           |
| **[SIN ACTIVAR]**             | El componente existe o es reconocido, pero actualmente no está activo.                                                    | Depende del componente.                                                 |
| **[SUGERENCIA]**              | Lynis identifica una oportunidad para revisar o fortalecer la configuración.                                              | **Requiere análisis.** No equivale automáticamente a un hallazgo.       |
| **[INSEGURO]**                | Indica una exposición elevada según la evaluación realizada, en tu archivo principalmente por `systemd-analyze security`. | **Requiere revisión**, pero no implica automáticamente riesgo crítico.  |
| **[MEDIO]**                   | La prueba correspondiente sitúa el elemento en un nivel intermedio de exposición/protección.                              | Requiere contextualización.                                             |
| **[PROTEGIDO]**               | El componente presenta un nivel de protección favorable según esa prueba.                                                 | Generalmente favorable.                                                 |
| **[DÉBIL]**                   | La configuración evaluada podría fortalecerse.                                                                            | **Sí amerita revisión.**                                                |
| **[PELIGRO]**                 | Lynis detectó una condición especialmente desfavorable en esa prueba.                                                     | **Sí, debe investigarse.**                                              |
| **[POR DEFECTO]**             | Se mantiene la configuración predeterminada en lugar de un ajuste específico de hardening.                                | No necesariamente. Debe evaluarse.                                      |
| **[BASTIONADO]**              | La configuración incorpora las medidas de hardening esperadas por la prueba.                                              | Generalmente favorable.                                                 |
| **[PARCIALMENTE BASTIONADO]** | Algunas medidas de hardening están presentes, pero no todas las evaluadas.                                                | Puede requerir mejora.                                                  |
| **[DIFERENTE]**               | El valor actual no coincide con el valor esperado en el perfil utilizado por Lynis.                                       | **Debe analizarse.** Diferente no significa automáticamente vulnerable. |
| **[OMITIDO]**                 | La prueba no fue ejecutada o fue excluida en esa ejecución.                                                               | No permite concluir cumplimiento/incumplimiento.                        |
| **[DESCONOCIDO]**             | Lynis no pudo determinar el estado del elemento.                                                                          | Requiere verificación adicional.                                        |
| **[SÍ] / [NO]**               | Respuesta directa al criterio específico que Lynis está comprobando.                                                      | Depende completamente de la pregunta evaluada.                          |

Los estados entre corchetes de Lynis no representan necesariamente niveles de criticidad o riesgo. Su significado depende de la prueba que se esté ejecutando. El auditor debe interpretar cada resultado dentro de su contexto antes de determinar si constituye un hallazgo.
